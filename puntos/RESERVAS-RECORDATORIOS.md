# Recordatorios de reservas — MVP

Proyecto existente: manos-monas-puntos. Funciones en us-central1, agenda America/Lima. Desplegar desde puntos/ con firebase-tools en el proyecto existente. Activar Blaze, Cloud Scheduler, Cloud Messaging Web y generar clave pública VAPID; colocarla en MANOS_MONAS_VAPID_KEY. No desplegar las reglas sin probarlas con emulador y preservar las reglas actuales. Los avisos de citas de las 15–21 h se planifican a las 8:00 y una hora antes; solo se envían para citas confirmadas, nunca a la especialista. Si se crea la cita después de una hora programada, ese recordatorio no se envía retroactivamente. El registro del aviso en Firestore se deduplica por cita y fecha/tipo (y hora para aviso de una hora). Push es best effort, no se garantiza la entrega exacta; el inbox conserva el aviso aunque no haya token. La web requiere permiso y en iOS acceso desde la pantalla de inicio. Revalidar con dispositivos físicos, incluidos permisos denegados y cambios/cancelaciones. No se ha desplegado ninguna función ni regla en Firebase.
